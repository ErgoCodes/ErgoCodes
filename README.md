### Hi, I'm Andy

Fullstack developer (TypeScript, React, Node.js) from Cuba, now based in Curitiba, Brazil. I learned to build software on slow, expensive connections, so I care about things that keep working when conditions aren't ideal: offline-first apps, small payloads, explicit failure modes.

Most of what I build starts with a problem I actually had.

**What's here**

- **[olx-aluguel-mcp](https://github.com/ErgoCodes/olx-aluguel-mcp)**: when I moved to Brazil I needed an apartment and kept running into rental scams. This MCP server lets Claude search OLX, break down the real monthly cost and score each listing's scam risk.
- **[workana-mcp](https://github.com/ErgoCodes/workana-mcp)**: scores freelance projects by stack fit, competition, budget and client history, and recovers the results Workana hides from logged-out users.

- **[Saas-Multitenant](https://github.com/ErgoCodes/Saas-Multitenant)**: real-time boards, kanban and calendar (NestJS, Next.js, Socket.IO), growing step by step into a multi-tenant SaaS.
